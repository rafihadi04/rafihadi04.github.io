Resolume Arena Application Timer

An open-source, precision desktop show timer built specifically for live event visual operators (VJs), stage managers, church media directors, and broadcast technicians. Synchronizes countdowns, count-ups, and overtime tracking directly into Resolume Arena Text Blocks, streams transparent NDI 6 video feeds, and broadcasts web confidence monitors with remote mobile controls.

Precision Timer Modes: Countdown, Count-up, and Overtime (+00:02:15) with speed remapping (0.25x – 2.0x).
Native NDI® 6 Output: Direct low-latency video feed for OBS, vMix, and switchers with 32-bit alpha transparency.
Web Confidence Monitor: Full-screen downstage output (`/output`) for speaker confidence screens on LAN.
Mobile Wi-Fi Remote: Scan QR code from any smartphone to control timers, speeds, and stage notes over local Wi-Fi.
Stage Attention Strobe: Full-screen high-impact alert flash overlay for urgent cues on stage.
Zero Freezing Heartbeat: Background throttle bypass and sleep prevention ensures 0% timing drift.
